# 交底模板（docs/handoff/TEMPLATE.md）

> 目的：让任何一份交底都按同一形状写，接手的人 30 秒能定位「结论 / 改了什么 / 怎么验 / 还剩什么」。

---

## 形状（固定五段）

```markdown
# US-xx 交底：<一句话说清交付>

> 基线：<commit> · 日期：<YYYY-MM-DD>
> 判据：<故事地图里的判据原文>

---

## 1. 结论
<先给答案。一句话。>

## 2. 改动
<表格：文件 | 改了什么>

## 3. 验证
<表格：命令 | 结果。必须是真的跑过。>

## 4. 未做
<点名没做的部分。没有就写「无」。不许省略。>
```

---

## 规则

| # | 规则 |
|---|---|
| 1 | 第一段必须是**结论**，不许铺垫 |
| 2 | 「验证」里的每条命令都必须**真跑过**，贴实际输出 |
| 3 | 「未做」必须存在。没做就写「无」，不许删掉这一段 |
| 4 | 数字标来源（本机实测 / CI run id / 经验值） |
| 5 | 不超过 5 段。超了就拆文件 |
